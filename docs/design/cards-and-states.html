Cards that stand out, and every state in words

Two changes to how Voice Verses looks. The app as it is today sits beside each proposal. Nothing here changes what the room sees: only the operator's screens.

1. Cards that never blend into the page

Each card that holds something gets a fine gold-tinted edge and a soft shadow, so it reads as one thing on the page. Inside a card nothing changes: no lines, no boxes in boxes. In the dark theme the cards already stand apart, so the edge is a choice; in the light theme (warm paper, when it is built) cream on cream would blend in without it.

My recommendation: keep the dark theme as it is (its cards already stand apart) and make the edge the rule for light mode when it is built. Say if you would like the edge in dark too.

2. Every state in words, with the one thing to do

Every list and panel that loads, can be empty or can go wrong shows what is happening in plain words, and offers the one button that helps. Flip each panel between its states.

The live screen's library: Songs

Services: a day

Media: adding a file goes wrong

A field that's wrong: ProPresenter's address

Now. Settings → ProPresenter → Type the address yourself: a wrong address is only found out when Connect fails, as a message in the corner.
